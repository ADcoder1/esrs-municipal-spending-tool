# Gap Analysis Template

Use this template to document whether a disclosure or analytical question can
be supported by the available municipal data.

| Code | Topic | Status | Municipal fields | Transformation needed | External source |
| --- | --- | --- | --- | --- | --- |
| E1-1 | Transition plan | Missing |  |  | Climate strategy documents |
| E5-4 | Resource inflows/outflows and waste | Covered or transform | Procurement category | Category lookup |  |

## Status Definitions

- `Covered`: available directly in the source data.
- `Needs transform`: derivable with lookup, filtering, aggregation, or joining.
- `Missing`: requires another system, document, or narrative input.
