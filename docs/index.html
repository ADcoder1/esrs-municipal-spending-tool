ESRS Municipal Spending Tool

Public browser demo for exploring ESRS classification logic. The main municipal workflow lives in the local analysis app. This public page uses synthetic sample data. If you upload local CSV or Excel files, they are processed in your browser and are not sent to a server.

Prototype scope: This demo is for exploring classification logic and review workflows. It does not calculate environmental performance or produce formal ESRS disclosures. Excel support reads the first worksheet in the uploaded file. Very large Excel workbooks should be run in the local analysis app instead.
