ESRS Municipal Spending Tool

A browser-based workspace for reviewing municipal spending against ESRS environmental themes. Upload a CSV or Excel file and it is processed in your browser: nothing is sent to a server.

What this tool does: It provides a transparent first-pass classification and highlights the contextual checks needed for broad categories such as construction, transport, food and green space. It does not calculate environmental performance or produce formal ESRS disclosures. Excel support reads the first worksheet in the uploaded file.
