How this tool is used

Built for collaborative category review

Use this workspace to check how spending categories are being mapped, spot unclear classifications, and prepare a review package that can be discussed with city colleagues.

For review discussions

Focus on uncertain mappings, high-value categories, and rows that may need a stricter “None” interpretation.

Not a disclosure engine

This supports internal assessment and follow-up. It does not produce formal ESRS disclosures or environmental performance calculations.

Local by default

Files are processed on this computer so municipal data can stay in its original working environment.
